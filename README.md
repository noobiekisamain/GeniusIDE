**GeniusIDE** by **Cobalt Studios** is a high-performance, lightweight Integrated Development Environment designed to streamline code editing, debugging, and project management.

---

## 🚀 Features

* **⚡ Fast & Lightweight:** Instant startup times with minimal memory overhead.
* **🧠 Smart Code Editing:** Built-in syntax highlighting, intelligent auto-completion, and code formatting.
* **💻 Integrated Terminal:** Run build tools, scripts, and command-line interfaces seamlessly within the app.
* **🎨 Clean Workspace:** Distraction-free, modern interface designed to keep you focused.

---

## 📥 Installation

1. Download the latest version of GeniusIDE for your platform.
2. Follow the setup steps for your OS:
   * **Windows:** Execute `GeniusIDE-Setup.exe` and follow the setup wizard.
   * **macOS:** Open `GeniusIDE.dmg` and drag the application to your `Applications` directory.
   * **Linux:** Unpack the binary archive or install via `.deb`/`.rpm` packages.
3. Launch **GeniusIDE** to get started!

---

## 🛠️ Quick Start Guide

1. **Open a Project:** Go to `File` > `Open Folder...` to load your project directory.
2. **Customize:** Access `Settings` / `Preferences` to configure your editor themes, keybindings, and extensions.
3. **Run Code:** Open the built-in terminal (`Ctrl + ~` / `Cmd + ~`) or use custom run scripts to execute your code.
